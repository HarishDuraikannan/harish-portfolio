# Harish D. — Frontend Developer Portfolio

A premium, light-theme, responsive React portfolio built with Vite, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js 20.19+ (or 22.12+).
2. Extract this ZIP and open the folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`. The production output is created in `dist/`.

## Personalize before publishing
- Replace `your.email@example.com` in `src/App.jsx` with your email address.
- Replace the GitHub and LinkedIn profile URLs in the footer with your actual profiles.
- Review project descriptions and add real demo / repository URLs where available.
- Update the experience figure and skills if needed.
- Your supplied first photo is used as the main hero image. Your second photo is used in the About section and as a small secondary portrait.

## Stack
React 18 · Vite · Tailwind CSS · Framer Motion · Lucide React
